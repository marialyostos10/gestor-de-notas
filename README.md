# Gestor de Notas

Aplicación web simple para crear y organizar notas dentro de carpetas.

## Descripción

Este proyecto es un gestor de notas que permite:
- Crear, editar y eliminar carpetas.
- Crear, editar y eliminar notas dentro de cada carpeta.
- Guardar los datos en `localStorage` para mantenerlos entre sesiones.
- Cambiar entre tema claro y oscuro.

## Archivos principales

- `index.html` - Estructura de la aplicación y modales.
- `style.css` - Estilos y diseño responsive.
- `script.js` - Lógica de la aplicación, manejo de carpetas, notas, temas y almacenamiento local.

## Cómo usar

1. Abre `index.html` en tu navegador.
2. Haz clic en el botón `➕` de `Carpetas` para crear una nueva carpeta.
3. Selecciona una carpeta y haz clic en `➕ Nueva Nota` para agregar una nota.
4. Usa los botones de editar y eliminar para administrar carpetas y notas.
5. Cambia el tema con el botón `🌙` / `☀️`.

## Requisitos

Ninguno. La aplicación es una página estática que funciona en cualquier navegador moderno.

## Notas

Los datos se almacenan localmente en el navegador, por lo que no se comparten entre dispositivos ni navegadores.
